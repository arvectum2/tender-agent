Это завершает *разбор* всех шести исключений, но не подтверждает исправление исходных противоречий площадкой.

**СИБУР:** один существующий автономный обработчик продолжает индексирование. При последнем подтверждении **23.11.2026 13:02 UTC** в реестре **7 175** indexed из **7 798** currently eligible, то есть **92,01%**, **623** ещё в очереди. Data Platform — **9 344** документа, 107 273 chunks и embeddings (равны). Источник — `autonomous-runner/state.json` и собственный контроль очереди `member-index-auto-...`. Знаменатель динамический, показатель не равен доле всего публичного рынка СИБУРа. Режим resource governor `reduced` с пакетом 3, `verified_pitr` PASS, прежний единственный PID 59010; ускорение через отключение ограничителей, второй воркер, рестарт LLM или PG не использовались.

## Следующий контроль СИБУРа

Текущая задача **не может быть объявлена полностью выполненной**, пока динамический хвост пригодных файлов не станет 0 или отдельные файлы не будут доказательно переведены в review. Сохранять работающий единственный обработчик и `verified_pitr` prewrite gate; при проверке читать свежие `state.json`, `member_queue.file` и серверные DP stats, сверять новый прирост, причины review и аппаратные лимиты. Не считать 100% завершением обработки всех видов закупок СИБУРа, поскольку это очередь только eligible members.

Дальнейшее внешнее действие по двум аномалиям дат — получение официальной истории редакций/разъяснения ЭТП ГПБ; без такого подтверждения безопасная очистка карантина невозможна.
