# MI-002 Power Quality — операционный протокол и границы данных

Дата снимка: 2026-10-24. Период: **24.10.2023–24.10.2026**. Версия данных: `power-quality-seed/0.1`.

## Что фактически есть

- 12 независимо обнаруженных **процедур/потребностей**, не 12 заключённых договоров и не репрезентативная совокупность закупок РФ.
- 2023: 1; 2024: 1; 2025: 3; 2026: 7. **Это распределение видимости по годам, не динамика рынка**. Из 12 только 8 дат помечены `published`, две — `published_secondary`, одна — дата начала приёма, одна — дата окончания приёма вместо отсутствующей публикации.
- Семейства: 5 STATCOM, 6 УКРМ, 1 активный фильтр гармоник. Пакеты: 7 поставок, 2 EPC/под ключ, 1 проектирование, 2 сервис.
- Сведения о 11 закупках подтверждены только вторичными карточками, 1 закупка доступна на публичной странице оригинальной коммерческой ЭТП Bidzaar. Уровень `primary_platform` **не означает проверенный протокол/победитель**.
- Прямых документально проверенных победителей / цен договоров в срезе **0**. Это статус верификации, а не утверждение, что победителей или заключённых договоров нет. `market_size_rub=null`.
- Часть агрегаторов показывает НМЦК, итоговую сумму другого типа или 0 ₽ в карточке. Запрещено трактовать это как стоимость товарной позиции, реальную контрактную цену или бесплатную поставку.

## Измеренный блокер

Первичное тестирование штатного прямого поиска ЕИС с Mac mini:
- 223-ФЗ, поисковые фразы «УКРМ» и «СТАТКОМ», 01.01–24.10.2026: HTTP 434 для обоих запросов.
- 44-ФЗ, те же две фразы, тот же период: HTTP 434 для обоих запросов.
- Использован текущий `Public44FzSearchProvider` и `Public223FzSearchProvider` с `bypass_proxy=True`. Не выполнялись капча-обход, авторизация, массовый запрос или повторная агрессивная нагрузка.
- Сырой JSON диагноза: `data/market_intelligence/power_quality/eis_access_probe_20261024.json`.

**Важно:** прямой публичный поиск ЕИС недоступен в проверенной схеме, но это ничего не говорит о полноте реестра или доступности разрешённых альтернативных интерфейсов; нельзя считать EIS "нулевым рынком". SOAP `getDocsIP` по известным номерам полезен для документов, но не решает обратный семантический поиск всех номеров и не заменяет реестр протоколов/договоров. Не принимать неподтверждённые сторонние карточки за официальный реестр.

Полная модель за три года требует покрытия источника × месяца × вида факта (извещение, приложения, протокол, договор) и отдельно источника без обязательной публикации. Без известных знаменателей нельзя выдавать `TAM`, `market share` и `win rate`.

## Что внедрено в данном срезе

- `data/market_intelligence/power_quality/ontology.v1.yaml` — положительные технические термины, исключения, контекстные признаки для УКРМ/СТАТКОМ/тиристорной компенсации/фильтров/комплексного PQ.
- `data/market_intelligence/power_quality/verified_public_leads.v1.json` — **посещённые и прочитанные публичные источники**, даты и их природа, локаторы, цитаты, исходные номера, статусы `reported`, контрагенты из карточек, отдельно `reported_total_rub` (непроверенная цена полного EPC).
- `src/modules/market_intelligence/power_quality_pilot.py` — нормализация, валидация, дедуп, передача из доказательной базы в MI-001, отчёт по источникам/семействам/годам, приоритет организаций на основе *наблюдаемой* активности без имитации победителей и продаж.
- `data/market_intelligence/power_quality/pilot_report.v1.json` — воспроизводимый machine-readable результат.
- `docs/market_intelligence/POWER_QUALITY_PILOT_20261024.md` — читаемый обзор с документальными ссылками, caveats и гипотезами коммерческого выхода.

## Запуск

Из корня изолированного рабочего дерева Tender Agent при установленном Python-окружении:

```bash
python -m src.modules.market_intelligence.power_quality_pilot \
 --seed data/market_intelligence/power_quality/verified_public_leads.v1.json \
 --ontology data/market_intelligence/power_quality/ontology.v1.yaml \
 --access-probe data/market_intelligence/power_quality/eis_access_probe_20261024.json \
 --json-out data/market_intelligence/power_quality/pilot_report.v1.json \
 --md-out docs/market_intelligence/POWER_QUALITY_PILOT_20261024.md
```

## Ограничения безопасности и качества

- Используются только публично наблюдаемые карточки без обхода ограничений/капч и регистрации; условия переиспользования данных проверяются до регулярного массового сбора.
- Сторонняя карточка НЕ является доказательством оригинального протокола. Отрицательный факт «нет заявок» пока именно вторичное свидетельство, требующее повторной сверки.
- Контакты сотрудников, встречающиеся на сторонних страницах, не включены в отчёт и не используются для автоматической рассылки.
- Даты и статус карточек могут конфликтовать — отдельно отмечены в seed. Указанный в агрегаторе город публикации может не совпадать с местом объекта.
- Фактической выборки открытых процедур на 24.10.2026 в реестре MI-002 нет; **это не значит, что таких процедур нет в России**.
