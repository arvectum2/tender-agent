## Реализованный инженерный инкремент

- `qualify_llc_response` повторно использует существующий `triage_corporate_card`, проверяет исходный HTTP/SHA и не подменяет положительными признаками отсутствующее подтверждение допуска ООО, обязательной квалификации, доступа или экономики.
- Даже при всех положительных подтверждениях состояние — `HUMAN_GO_REQUIRED` и `response_authorized=false`; функция не совершает внешних действий.
- Детерминированная команда генерации из существующих файлов, без сети и обращений к аккаунтам:

```bash
python -m scripts.b2b_llc_eligibility_snapshot \
  --as-of '2026-10-17T21:22:00+03:00' \
  --output docs/roadmap/b2b_llc_eligibility_snapshot_2026-10-17.json
```

Для нового времени нужно повторно получить достоверные первоисточники и их время наблюдения: значение `as-of` не превращает старый снимок в актуальную проверку.
