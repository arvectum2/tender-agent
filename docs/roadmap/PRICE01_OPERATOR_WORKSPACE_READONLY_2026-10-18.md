# PRICE-01 — read-only ценовой контекст в едином Operator Workspace

**18.10.2026, ООО «Арвектум».** Продолжение [PRICE-01/Aksay 55/55](PRICE01_AKSAY_PROTOCOL_EVIDENCE_AND_COST_SCENARIOS_2026-10-17.md), НЕ закрытие всего PRICE-01. Канонический интерфейс: /pilot/tender-agent/workspace под штатной пилотной аутентификацией.

## Реальная реализация

- **Единый кабинет:** новая вкладка «Цены и протоколы» в действующем HTML/JS. В базе закупок для 19-значных номеров появляется ссылка в этот раздел.
- **Проверенный первоисточник:** приватный GET /api/demo/tender-agent/workspace/competitive-prices/{registry_number} использует уже сохранённый агрегат price01_aksay_original_protocol_baseline_2026-10-17.json **только** для 0158300034526000388. Дополнительно проверяются ожидаемые SHA оригинального ZIP/официального XML/двух экспортов, число/ранг/цены и отсутствие рекомендованной ставки. Не создаётся вторая БД, нет доступа к рабочим копиям ArvectumSSD из сервера.
- **Fail closed:** другой номер и неизвестная закупка дают 404 — нет доказательной выборки; повреждение или отсутствие сохранённого агрегата даёт 503 — данные недоступны. Не превращать отсутствие источника в нулевую цену или ставки Аксая для другого тендера.
- **Ограниченное API:** возвращаются только 45 допущенных, 10 отклонённых, пять агрегированных статистических цен, 28 400 ₽ победителя, 119 000 ₽/38-е место ООО, агрегированные причины отклонения и SHA. 55 поимённых записей, полный текст решений комиссии и оригинальные XML не отдаются браузеру.
- **НМЦК отдельно:** по нажатию кнопки используется уже существующий API /api/tender-research/historical-prices/{registry_number} из ARV-057. Если его защита сопоставимости не возвращает AVAILABLE, UI показывает недостаток данных; **исторические НМЦК никогда не называются допущенными финальными предложениями**.
- **Жёсткие рамки:** одна сопоставимая закупка в первичной выборке (cross_procurement_comparison_state=INSUFFICIENT_EVIDENCE); источник затрат/труда/комиссий/налоговой оценки/целевой прибыли не дан (cost_scenarios=null), forecast/bid recommendation=false. Ни ставок, ни заявок, ни расходов.
