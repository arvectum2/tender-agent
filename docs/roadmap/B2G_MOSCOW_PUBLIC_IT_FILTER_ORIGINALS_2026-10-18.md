# Москва: шесть публичных IT-поисков и три оригинальные котировочные сессии

**18 октября 2026, 11:00–11:15 МСК.** По официальному [Порталу поставщиков Москвы](https://zakupki.mos.ru/) выполнено шесть **штатных поисков интерфейса** в публичном реестре котировочных сессий. Headless Chrome запускался без аккаунта и пользовательских cookies, с одноразовым профилем исключительно на ArvectumSSD. Навигация проходила не по угаданным API, а существующей кнопкой **«Реестр котировочных сессий»**, затем **«Показать фильтры» → «Наименование закупки» → «Применить»**. Каждый реально применённый запрос сверялся с URL реестра и установленным состоянием «Активные»; только **первая страница выдачи** каждого запроса.

[Машинное свидетельство: шесть поисков, источниковые номера и SHA трёх исходных карточек](b2g_moscow_6_queries_and_3_original_goods_2026-10-18.json). Исходные HTML-страницы (около 11–12 МБ каждый) и личные cookie **не добавлены в Git**. Данные относятся только к дате проверки, **не к текущей доступности в будущем**.

Из реестра не делались ставки, акцепты или регистрации.

**Вывод:** шесть поисков и три первичных IT-looking товарных лота **не принесли ни одного доказанного контракта на заказную разработку ПО**. Механизм поиска повторяем и пригоден для следующего более точного прохода. Это не показатель неэффективности всего портала, а доказательство того, что поверхностная выборка по словам «разработка» и «программного обеспечения» создаёт ложные лиды.
