## Новая автоматизированная проверка

Модуль scripts.price01.audit_original_website_cohort повторно читает **локально и только для чтения** шесть оригинальных ZIP и DOCX: проверяет источниковые SHA, точную редакцию извещения, реестровый номер, обязательные текстовые якоря в технических заданиях, исходные applicationInfo, admitted, rank и finalPrice. Итог содержит **агрегаты** без копирования исходных XML и поимённых предложений в репозиторий.

- [x] Установлены 6/6 оригинальных закупок, 6/6 оригинальных ТЗ и хеши.
- [x] В 5 протоколах допущенные цены есть, в EOK20 нет конечной цены: не подменять её НМЦК или ценой контракта.
- [x] 0,01 ₽ сохраняется как выброс источника, не округляется до нормальной рыночной цены.
- [x] Каждая процедура считается **одним заказом**, не числом принятых предложений, и не смешивается с иными типами работ.
- [ ] Для двух близких сайтов — отдельно нормализовать объём дизайна, страницы, сроки, российские CMS/Битрикс, лицензии, поддержку, интеграции и объём контента.
- [ ] Найти несколько действительно **эквивалентных** завершённых сайтов; до этого **не** объединять все шесть протоколов в одну медиану.
- [ ] Получить реальные прямые расходы ООО, труд, налоги/платформенные ставки, резерв и минимальную прибыль для ценового предложения.
- [ ] Расширять Operator Workspace на другие протоколы только после source-bound и интерфейсных проверок.

**Итог:** дополнительные завершённые процедуры с проверенными результатами есть, но среди пяти новых **2 близкие, но ещё не нормализованные** и **3 с другим результатом/рисками**. Сопоставимая с Аксаем подтверждённая группа до нормализации остаётся из одного проекта. Никаких ставок и прогнозов победы, внешних откликов, платежей, изменений в production не сделано.
