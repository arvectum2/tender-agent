# Портал поставщиков Москвы: публичный реестр открылся в изолированном Chrome

**18.10.2026, без авторизации, без личных cookie и без подписания.** Этот этап дополняет [юридический аудит официальных регламентов](B2G_MOSCOW_SUPPLIER_OFFICIAL_ENTRY_2026-10-18.md). Прямой HTML главной страницы zakupki.mos.ru был только JavaScript оболочкой. Поэтому на Mac mini был запущен **новый временный изолированный профиль Chrome на ArvectumSSD**, не личный браузер компании, и пройдено публичное навигационное действие: кнопка **«Реестр котировочных сессий»** на [официальном главном экране](https://zakupki.mos.ru/). После достаточной загрузки браузер перешёл на оригинальный раздел /purchase/list с активными публичными котировочными сессиями. Временный профиль удалён после завершения.

**Что действительно появилось в первичном UI:** номер сессии, исходное название, публичный статус, заказчик и ИНН, начальная стоимость, федеральный закон, точное время окончания по МСК, ссылка на оригинальную карточку. Пример из первого экрана:

| Поле | Данные первичного реестра |
|---|---|
| № | **10321388** |
| Предмет | **Растворители (разбавители)** |
| Заказчик | Московский театр на Таганке; ИНН **7709010548** |
| Начальная цена | **44 700 ₽** |
| Опубликованный статус | **«АКТИВНАЯ»** |
| Дата окончания | **20.10.2026, 10:00 МСК** |
| Режим | **223-ФЗ** |
| Для ООО Арвектум как IT-разработчика | **Нет — не IT, не добавлять в подбор** |

Это **выписка из публичного списка**, а не полный просмотр оригинального ТЗ и не подтверждение возможности заявиться. [Минимальная машиночитаемая квитанция](b2g_moscow_public_registry_browser_2026-10-18.json) не содержит исходный HTML, cookie, учётные данные или частные документы и честно помечает детализацию лота как непроверенную.

## Что удалось и что не завершено

- [x] Получить полноценную публичную JavaScript-страницу первоисточника, не только 200 OK статический shell.
- [x] Через фактическую кнопку интерфейса попасть в публичный реестр котировочных сессий, где появились идентификаторы, статусы, цены, ИНН и реальные часы окончания по Москве.
- [x] Подтвердить один пример не-IT, исключить его из Arvectum lead-счётчика.
- [x] Проверить технику в изолированном браузерном профиле, не логиниться в учётку ООО, не отправлять предложений и не трогать чужую рабочую среду.
- [ ] **Поиск по IT:** выбрать публичный фильтр по услугам разработки, сопровождению, интеграции и ПО; для каждой найденной карточки открыть её оригинальный ТЗ и проверить срок, статус, начальную цену, юрлицо заказчика и возможные ограничения.
- [ ] Автоматическое чтение фильтров UI в этом запуске не было продолжено; не выдавать увиденные товары с первой страницы за «15–20 активных IT тендеров».
- [ ] Проверить, разрешено ли ООО Арвектум подаваться через фактический аккаунт и ЭП. Регистрация email-only даёт просмотр, не участие; не совершать действий от имени компании без отдельного GO.

**Отдельная категория B2G:** ни открытый реестр, ни отдельная карточка растворителей **не дают новых B2B-заказов**. Текущий подтверждённый счётчик непосредственно пригодных ООО IT-сессий по этому источнику — **0**, поскольку IT-список и документы не проверены, а не потому, что таких сессий на площадке не существует.
