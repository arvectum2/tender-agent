# SIBUR archived procurement parser — isolated first-party page audit, 21 November 2026

This source-only proposal was extracted from the large historical DRAFT PR #527, which combines more than 60 files and 7k inserted lines, including independently permissioned DB writers, crawlers, Data Platform operations and sales analysis. **None of those operations is included in this bounded source parser.** Original PR #527 and its historical receipts remain unchanged and DRAFT.

`archive_parser.py` is an offline parser/URL constructor for **nine explicitly specified** SIBUR procurement archive categories (107, 108, 109, 112, 132, 999_08, 999_10, 999_11, 999_19). It enforces exact source category/page identity, HTML table headers and privacy-redacted row projections, source pagination bounds and strictly allowlisted `https://www.sibur.ru/upload/tmp/example/` links. Outside-origin or ambiguous links are marked unverified, not silently trusted as originals. Duplicate JSON payload members now fail closed. There are no network calls, workers, database writes, document downloads, source grants or ETP applications.

An independent **read-only**, private, SHA-bound audit replayed **one real archived first-party page per category** from previously stored source bytes and signed-by-content receipts (9/9 category pages, 108/108 original row identities and their exact ordering). Actual source-reported maximum page counts at historical observation were: `107`=473, `108`=1075, `109`=202, `112`=942, `132`=787, `999_08`=151, `999_10`=203, `999_11`=214, `999_19`=5. The verified nine pages each contained 12 rows. The offline test checked SHA256/byte length, first page=1, category, exact source URL, parsed pagination, row count, and IDs against each private first-party capture receipt. The private 0600 evidence report is at `/Volumes/ArvectumSSD/Arvectum/private/tender-agent/sibur-archive-category-page-audit-20261121.json` and contains no HTTP secrets or source bytes in the Git repository.

**Limit:** nine page-1 receipts are a **parser proof and category coverage sample**, NOT a verified contiguous all-pages historical archive, still less proof that all listings are active today. The far larger displayed source pagination is historical metadata only, not a claim all those pages were acquired or that an archive result is commercially relevant. Subsequent source collection/integrated indexing require separately reviewed rights, first-party originals, bounded processing, MI/PITR and owner authorization. One `.ppt` URL to saved `.pptx` discrepancy in the **current** SIBUR document snapshot remains quarantined under [#686](https://github.com/arvectum2/tender-agent/issues/686); this parser does not adjudicate it.

The new `replay_archived_page(source_dir, category, page)` is the reusable **read-only first-party source admission primitive**: source category/page validated before filesystem access, receipt filename pinned to the exact `page + SHA256` structure, receipt JSON duplicate members rejected, symlinks/unsafe directories rejected, raw original bytes SHA256 checked, and parsed row IDs/count/pagination/source URL checked against the exact saved receipt. It was run successfully on all nine actual independent historical page-1 files. Additional negative tests reject modified raw bytes, false IDs/category, path traversal, symlinked raw files and duplicate receipt keys. **32 focused source-parser tests PASS, Ruff PASS.** This accepts only historical bytes at a pinned capture point, not evidence that 2026-11-21 live SIBUR archive status or all pages were checked.
