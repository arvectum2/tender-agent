# PRICE-01 — шесть исходных сайтов в едином приватном Operator Workspace

**18.10.2026.** Шесть проверенных ЕИС оригиналов и ТЗ собраны в [source-bound cohort](PRICE01_WEBSITE_OFFICIAL_COHORT_2026-10-18.md); их **публичные агрегаты** отдельно отображаются в уже существующей вкладке «Цены и протоколы».

## Реализованное

- [x] Приватный read-only API: /api/demo/tender-agent/workspace/website-price-cohort; штатная защита пилотного workspace требует Basic Auth.
- [x] API повторно проверяет точный SHA-256 зафиксированного JSON-корпуса и схема/числа/версии/оригинальные source SHA. Неверная подпись источника или отсутствующий агрегат => **503**, без fallback.
- [x] Возвращаются **только** шесть независимых агрегированных карточек: предмет ЕИС, всего заявок/допущено/отклонено, min/median/max только admitted finalPrice при наличии, оригинальные SHA ZIP/XML/ТЗ и мотивировка расхождения объёма. **Нет полных участников, их ID, индивидуальных ставок или юридических сведений**.
- [x] В существующем UI появилась отдельная кнопка «Показать 6 проверенных архивных сайтов»; карточки показывают **источниковую аномалию 0,01 ₽** и явное отсутствие finalPrice для конкурса СПб. Единая медиана сайтов **не вычисляется**.
- [x] Исходный API Аксая /workspace/competitive-prices/{registry_number} **не менялся**: остальные пять реестровых номеров по-прежнему дают **404**, пока нет настоящей нормализации сопоставимости.
- [x] Следующий ARV-057 historical NMCK API остаётся отдельным действием и не считается ценой победителя.
- [x] Нет нового интерфейса вне канонического кабинета, второй БД, нового API для автоподачи или коммерческого решения.

## Границы

В протоколах 140 заявок, 124 допущены, но это **шесть** отдельных договорных объектов. Два близки по типу (Красноярск, санаторий «Чемал»), однако отличаются наполнением, платформой/интеграциями и сроками; три имеют другое ТЗ и/или оценочный режим. **0 дополнительных источников включено в ценовой пул Аксая; группа равноценных закупок остаётся 1**.

Следующая задача — source-bound количественная нормализация технических объемов этих двух близких сайтов, но если не хватает исходных человеко-часов/себестоимости, сохранить **UNKNOWN** и не рассчитывать псевдо-коэффициенты.

Текущий шаг подготовлен в **черновом PR #478**, production не менялся. Финальная приёмка интерфейса в живом staging и юридическое/коммерческое разрешение на реальные ставки — отдельно.
