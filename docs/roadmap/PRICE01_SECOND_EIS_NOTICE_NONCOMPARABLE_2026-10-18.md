## Исполнение

- [x] Оба исходных ZIP проверены по сохранённым official EIS SHA и первичным итоговым протоколам.
- [x] Выделены оригинальные предметы из последних исходных XML-извещений с отдельными SHA и версией.
- [x] Экспериментальная пара явно исключена по scope mismatch; её цены **не вошли** в распределение 45 допустимых ставок Аксая.
- [x] Adversarial offline тесты запрещают «повысить» кандидата при изменённой или недоказанной формулировке.
- [ ] Найти несколько новых завершённых закупок **на создание сопоставимого сайта**; проверять не только заголовок, но реальный состав ТЗ, CMS, объём контента, поддержку, сроки и условия передачи прав.
- [ ] При появлении подходящих конкурсов повторить source-bound проверку исходного итогового протокола, привязку ставок к конкретному предмету и только потом формировать распределение по нескольким независимым закупкам.

**Вывод для Operator Workspace:** один source-verified завершённый протокол по конкретной разработке сайта, один другой оригинал **исключён**, достаточной ценовой выборки для прогноза/предложения ставки нет. Временное сообщение «историческая выборка недостаточна» остаётся правильным. Не считать это обнаружением рыночной цены для всех ИТ-работ.

Результат НЕ означает, что компания не может участвовать в «Аксиоме»; лишь то, что цена разработки GIS-модуля не является сопоставимой ценой типового веб-сайта. Внешних заявок, оплат, изменений в production не выполнено.
