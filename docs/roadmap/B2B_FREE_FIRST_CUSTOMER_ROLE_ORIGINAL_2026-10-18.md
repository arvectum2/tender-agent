# ООО «Арвектум»: отделение реальных запросов заказчиков от объявлений самих исполнителей

**Дата исходных проверок: 18.10.2026.** Источники — только оригинальные first-party каталоги [CONTRACTIS: Программирование и IT](https://contractis.ru/order/c/programmirovanie) и [CodeLance: заказы](https://www.codelance.ru/orders), **7+12** прямых исходных ссылок, каждая повторно запрошена по точному HTTPS URL с HTTP200 без редиректов. [Машинная квитанция](b2b_free_first_real_customer_originals_2026-10-18.json) содержит SHA-256 всех первичных HTML, UTC времени, класс роли автора и дословный проверенный фрагмент, но не пересохраняет чужой исходный HTML.

На CodeLance даже открытый статус **«Открыт»** часто стоит на предложении исполнителя; одного статуса недостаточно.

## Исключённые примеры

В CodeLance 9 из 12 прочитанных **открытых** карточек представляли портфолио/объявления исполнителей «Сделаю сайт», «Могу разработать…», «предлагаю помощь с веб-разработкой» и т.п. Отсекаются по дословному исходному тексту конкретной карточки, а не по заголовку индекса. Дополнительная карточка с несложными действиями в соцсетях — не IT-разработка; отдельная карточка со сомнительным цифровым активом исключена из-за риска и несоответствия предмету. У CONTRACTIS №15 создание/оформление карточек Wildberries/Ozon — контентная задача, а не разработка сайта или ПО, хотя индексирована в «Программирование и IT».

## Смысл для дорожной карты

- [x] Для 19 карточек — оригинальные URL/хеши, принадлежность первичной категории и **строгое разделение роли «реальный заказчик»/«исполнитель продаёт себя»/«неподходящее»**. При изменении дословного доказательного фрагмента скрипт отказывает и не повышает до заказчика.
- [x] Дедупликация с ранее проверенными тремя заказами. Новых отдельных **описаний задачи** четыре; **новых подтверждённых ООО доступных сделок — ноль**.
- [ ] Для этих четырёх проверить текущую активность/право бесплатного первого ответа конкретного аккаунта, идентичность заказчика/ИНН, NDA, договор и оплату российского ООО. Без этого название «биржа» и исходные 200-й HTTP ответ не дают доступа.
- [ ] Текущая цель **15–20 уникальных действительно доступных ООО заказов** всё ещё незавершена: исходные 10 публичных корпоративных Workspace + 4 новых описания задач CONTRACTIS **не превращаются в 14 подтверждённых активных B2B-заказов**.
- [ ] Следующий проверяемый самостоятельный источник — свежие FL.ru для всех (а не платные отклики) или официальные котировочные сессии для российского юрлица; пересекающиеся публикации, например похожие заявки на AI-склад, нельзя считать независимыми.

Заказчикам никто не писал, компании ничего не регистрировалось/покупалось, не подавались заявки, не менялся production. Этот результат хранится в **draft PR #477**; последний word-by-word источник не заменяется ChatGPT-догадками.
