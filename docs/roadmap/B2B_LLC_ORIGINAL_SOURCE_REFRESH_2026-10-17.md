## Реализованный безопасный шаг

Скрипт `scripts/acceptance/refresh_workspace_llc_originals.py` повторно использует имеющийся строгий парсер исходной карточки и fail-closed юридический фильтр. Он работает только с пятью исходными HTTPS URL, проверяет точное место запроса без редиректа и исходные ключевые формулировки, сохраняет новую дату наблюдения и контрольную сумму. При недоступности или изменении обязательной структуры результат `SOURCE_REVIEW_REQUIRED`, **не** `PUBLIC_CANDIDATE_ONLY` или утверждение об отмене закупки. Ни один результат не превращается в разрешение на отклик.

Для нового сеанса публичной проверки (нужен сетевой доступ):

```bash
python -m scripts.acceptance.refresh_workspace_llc_originals \
  --out docs/roadmap/b2b_workspace_llc_live_recheck_2026-10-17.json
```

Датированный файл уже содержит точный результат этой проверки; повторный запуск в будущем должен сохраняться отдельной версией, а не выдавать прежнюю дату за сегодняшнюю.
