# R4 — фактические первоисточники второй слепой выборки

**15 октября 2026. Подготовлено 4 реальных набора ЕИС из плановых 12.** Ни по одному из них нет независимого юридического gold и результатов Tender Agent.

## Как подтверждены источники

План отбора не менялся: два заранее зарегистрированных каталога Tendigo, фиксированный порядок карточек и только конкурентные извещения 44-ФЗ. SHA плана: 8c7cd8ae0b916a277fb97949f66f6b891a6f73d7601f1f2b48b3063c838792c5.

После вчерашнего TLS-тайм-аута **обе страницы стали доступны**. Исходные HTML-байты, их SHA, время получения и URL сохранены приватно на внутреннем диске Mac mini. Универсальный парсер проверил метку закона и официальную ссылку ЕИС на одной и той же карточке. На каждой странице отображаются десять карточек: семь 44-ФЗ и три 223-ФЗ. Первые три уникальных извещения 44-ФЗ уже зарезервированы в первоначальной blind-выборке.

Следующие **четыре ранее не использованные по номеру** закупки получили авторизованный read-only getDocsIP. По каждой проверены официальный ZIP, последний XML, конкурентный тип извещения, версия и точный список исходных приложений. Получены все **21 исходный бинарный документ** (6 + 7 + 4 + 4), размеры соответствуют официальным XML; сохранены 21 уникальный SHA-256. Из исходников не извлекали юридические требования, не запускали предсказания модели и не создавали экспертные метки.

Универсальный source-lock guard теперь отказывает в фиксации неполного набора даже тогда, когда сохранённые файлы подлинные: проверяются количество, UID, расширение, размер и SHA каждого официального оригинала. 4 полных комплекта прошли техническую проверку на исходных байтах.

В GitHub публикуется только агрегат без оригиналов, внутренних путей и токенов: data/TA_R4_STAGE2_FIRSTPARTY_SOURCE_ACQUISITION_2026-10-15.json. Все исходные HTML, ZIP и вложения находятся в отдельном приватном локальном хранилище.

## Почему это ещё не готовый blind-lock

Внешний SSD ArvectumSSD остаётся смонтированным, но чтение содержимого репозиториев и checkpoint зависает. Точная ветка PR #432 скопирована на **внутренний диск**, исходный репозиторий на внешнем SSD не изменён. Не удалось прочитать предыдущий приватный immutable lock со всеми SHA 16 файлов первой независимой выборки.

Номера четырёх закупок не входят в старые 20 development-кейсов и не совпадают с тремя известными ранее отобранными номерами. Однако **проверка пересечений с предыдущими 16 бинарными SHA не выполнена**. Поэтому результат остаётся PRELOCK_PENDING. Публикация или создание второго окончательного blind-lock до этой проверки запрещены.

Цель второй когорты — 12; удалось собрать только четыре по фиксированным каталогам. Нельзя автоматически или вручную добирать другие номера с нарушением протокола, выбирать удобные ТЗ либо включать их в SUT.

**Нерешённые зависимости:** восстановление доступа к прежнему private lock; независимая квалифицированная юридическая разметка; freeze эталона до первого SUT-run. Подписанные gold = 0, precision/recall = NOT_MEASURED, bid_ready=false.
