# R4/R5 — восстановление первоисточников для 7 неполных архивных запусков

Проверка ChatGPT в этом чате через RDC, 12.10.2026. Исполнитель первичного извлечения утверждений — **локальная Gemma4-12B на Mac mini**. Никаких внешних LLM API, заявок, изменения production или оригинальных документов.

## Почему 7 запусков прежде не анализировались

Семь сохранённых запусков имели `status=docs_required`, и в их каталогах вообще **не было нормализованных текстов**. Значит, прежнее `source_documents_relevant=0` не доказывало отсутствия требований в документах — извлечение не запускалось. В четырёх запусках остались только XML из официального ZIP; в трёх были ещё исходные DOCX.

| Закупка | В старом запуске | Независимая проверка |
|---|---|---|
| `0127100008626000013` | 6 XML, нет DOCX | Только архивные извещения/протоколы; полный договор неизвестен |
| `0148200000526000028` | 5 XML + 2 DOCX | Оба DOCX восстановлены, контрольные суммы и прежняя официальная бинарная верификация подтверждены |
| `0149200002326001555` | 4 XML + 1 DOCX | DOCX восстановлен и проверен |
| `0349100009326000005` | 4 XML + 1 DOCX | DOCX восстановлен и проверен |
| `0349500000226000003` | 4 XML | Контракт/ТЗ в сохранённом запуске отсутствуют |
| `0360600005326000018` | 8 XML | Контракт/ТЗ в сохранённом запуске отсутствуют |
| `0895100000126000897` | 7 XML | Контракт/ТЗ в сохранённом запуске отсутствуют |

Общее число **7** относится только к запускам с документами из старого `getDocsIP`, но без нормализованных текстов. Отдельно существуют **3 закупки с `no_data`**, которые здесь не выдаются за успешно восстановленные.

## Проверка четырёх DOCX

Каждый локальный бинарный файл независимо сверялся с SHA-256 прежнего исходного инвентаря. Для всех четырёх официальная read-only файловая проверка, ранее зафиксированная в `bounded-filestore-verified72-private.json`, подтверждает исходный размер и хэш.

| Закупка | Документ | SHA-256 оригинала (сокр.) | Извлечённые символы |
|---|---|---|---:|
| `0148200000526000028` | Обоснование НМЦК | `f000205e0c0b` | 1 949 |
| `0148200000526000028` | Описание объекта закупки | `8142d03a1247` | 37 045 |
| `0149200002326001555` | Описание объекта закупки | `5018d0b63135` | 52 481 |
| `0349100009326000005` | Проект контракта | `aa2a23518568` | 44 600 |

Текст восстановлен **только локально** с сохранением хэшей оригинала и нормализованной выгрузки. Извлечение DOCX таблиц/параграфов **не удостоверяет** корректность невидимых диаграмм, сканов, встроенных изображений и юридическую полноту комплекта.

## Gemma — исполнитель; ChatGPT — отдельный эксперт

Gemma получила по три коротких, конкретно привязанных к оригиналу фрагмента на каждый из трёх кейсов. Всего 11 утверждений: **9 имеют буквальную цитату из восстановленного документа, 2 — не имеют**. Я прочитал сам исходный контекст и проверил также смысл:

- **8/11: SOURCE_AND_MEANING_SUPPORTED** с сохранением оговорок и контекста.
- `0148200000526000028`, четвёртое утверждение: **REJECT_QUOTE_AND_SCOPE**. Модель изменила начало цитаты и перенесла требование защищённых протоколов с удалённого администрирования ПО на любое обновление программного обеспечения.
- `0149200002326001555`, второе утверждение: **REJECT_EXACT_QUOTE**. В конце цитаты модель подменила закрывающие кавычки; факт неисключительной лицензии в полном тексте присутствует, но не подтверждён *этой точной цитатой*.
- `0149200002326001555`, третье утверждение: **REJECT_SEMANTIC_OVERCLAIM**. Оригинал запрещает предоставлять третьим лицам **право использования результатов оказания услуг**. Gemma без основания расширила это до полного запрета третьим лицам доступа к результатам.

Вердикты по 11 пунктам привязаны к оригинальным SHA-256 и сохранены приватно в `recovered-docx-20261012/chatgpt-independent-source-verdicts.json`; юридическая подпись владельца **не создавалась**.

## Выявленные реальные условия и риски

**`0148200000526000028` — официальный сайт Московской областной Думы.** В ТЗ прямо входят техподдержка сайта, продление и оплата домена `mosoblduma.ru`, обновление SSL-сертификатов и администрирование по защищённым протоколам SSH/SFTP. Это дополнительные обязательства и потенциальные внешние расходы; нельзя объявлять их выполненными без отдельного анализа сервисов и доступа. Простые ссылки ТЗ на нормативные акты о лицензировании сами по себе **не доказывают**, что лицензия обязательна для каждого участника.

**`0149200002326001555` — Инвестиционный портал Мурманской области.** ТЗ предусматривает отдельный объём разработки **110 человеко-часов**. Портал создан на ПО «Фактор», обладателем исключительных прав названо ООО «Интернет-Фрегат». Заказчик прямо указал, что **не может предоставить исходный код**; после договора возможен доступ только к конфигурационным файлам и данным. В описании существующего стека — PHP 7.3, MariaDB 10.4, PostgreSQL 9.6/PostGIS. Это существенный **риск реализуемости и интеграции**, который надо оценивать по реальному API, правам и доступам, а не объявлять заранее неразрешимым или автоматически разрешённым.

**`0349100009326000005` — сайт Управления Роспотребнадзора по Мурманской области.** В проекте контракта п. 2.1.9 прямо требует **лицензию на телематические услуги связи и государственную ИТ-аккредитацию**. В технических условиях требуется **минимум четыре штатных специалиста** сопровождения, а в п. 1.1.4 установлен срок от подписания до **31 декабря 2026 года** включительно. Это обязательные предметы последующей документальной проверки компании; существование документа **не доказывает**, что Арвектум соответствует или не соответствует этим требованиям.

Все три закупки — исторические: в проверенных архивных ZIP по ним есть итоговые протоколы. Ни одно из условий нельзя использовать для текущего GO без новой проверки живой карточки ЕИС и полной редакции требований.

## Статус после восстановления

Ранее **10/20** кейсов имели сохранённые предметные нормализованные тексты и отчёты; ещё **3/20** получили теперь хотя бы один проверенный оригинальный DOCX-текст для ретроспективного анализа. Значит, не более **13/20** имеют частичное предметное содержание для независимой смысловой экспертизы. У оставшихся **7/20** (4 XML-only и 3 `no_data`) полного предметного комплекта по-прежнему нет. Это **не оценка полноты всего контракта** для 13 кейсов.

Приватный локальный след: `recovered-docx-20261012/recovery-manifest.json`, `gemma-recovered-docx-private.json`, `chatgpt-independent-source-verdicts.json`. Новый код в production не применялся. **Текущий официальный статус ЕИС не удостоверен**, owner GO отсутствует; финальное решение пользователя — только в последней приёмке.
