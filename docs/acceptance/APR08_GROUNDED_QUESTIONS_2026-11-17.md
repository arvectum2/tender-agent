# APR08: ограниченные вопросы на естественном языке

Третий функциональный срез: существующий приватный Operator Workspace, новый POST `/api/demo/tender-agent/workspace/runs/{run_id}/evidence-answer`, без LLM, новой БД и внешнего действия. Полное совпадение с поддерживаемым русскоязычным вопросом (не подстрока) маршрутизирует к уже существующей проверке pinned XML (предмет, НМЦК, архивный дедлайн, явно заданный процент НМЦК) или ограниченному поиску оригинальных цитат (оплата работ/услуг, сроки, обеспечение контракта/заявки). Разные виды обеспечения не смешиваются на уровне интента; поиск остаётся лексическим, не доказывает полноту и смысл. UNKNOWN при неподдержанном, составном, юридическом вопросе или отсутствии подтверждения. Не автоматическая юридическая/коммерческая экспертиза; все результаты без GO/current/semantic approval. UI показывает ответ и соответствующий вид цитаты, сбрасывает устаревший результат.
