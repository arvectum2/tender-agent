## Excel: проверка конкретной исходной ячейки

r4_original_text_extract.py теперь принимает ограниченные по размеру **статические ячейки XLSX**, создавая локаторы SHEET-<имя листа> CELL-<ячейка>. Вход — исходный SHA-проверенный бинарный файл; xlsx открыт только для чтения, формулы не вычисляются, ошибки и формулы запрещены для автоматического цитирования. Составной ZIP с единственным XLSX тоже допускается. r4_external_gold_intake.py требует, чтобы дословная цитата действительно присутствовала **в указанной ячейке**, а не просто в другом месте файла. Ранее реализован аналогичный барьер для конкретного абзаца/ячейки таблицы DOCX.

Этот метод не анализирует автоматически изображения, диаграммы, формулы Excel, сканированные PDF, встроенные объекты или правовое значение условий. Извлечение текста отдельной ячейки **не доказывает полноту чтения всей закупочной документации**. Такие материалы блокируют автоматическую фиксацию неподтверждённых цитат и требуют квалифицированной ручной сверки. Тесты XLSX используют только искусственные книги; 16 оригиналов blind-когорты не передавались анализатору.

**Итог:** новая когорта зарегистрирована как намерение, не сформирована; прежние три blind-кейса нетронуты; human gold 0/3; семантическая precision/recall НЕ измерялась; bid_ready=false.

## PDF: локаторы страниц и неизменённая семантика

В r4_external_gold_intake.py дополнительно проверяется PDF-локатор PAGE-N: цитата должна находиться на **именно указанной странице** прямого PDF или PDF внутри ZIP. Проверка по всем страницам без привязки больше не принимается. Пустые страницы не выбрасываются, чтобы не смещались номера. Это текстовое подтверждение цитаты; сканированный слой, подписи, таблицы и правовой смысл остаются предметом визуальной/экспертной проверки.
