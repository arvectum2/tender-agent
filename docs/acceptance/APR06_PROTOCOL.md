## Per-case review and metrics

Operator writes /external/apr06/operator-reviewed/REG_NUMBER.json for each **completed** run with schema apr06-observation-v1:
- reg_number, law, source_manifest_sha256 (official notice digest), run_id, workflow_status=completed_with_human_review, started_at and analysis_evidence_ref.
- operator_review: reviewer_id, evidence_ref, decision=GO|NO_GO|DEFER and timezone-aware decided_at. These are attributable actual human events, never generated by the AI.
- suggested_decision: independent AI output GO|NO_GO|DEFER|UNKNOWN.
- claims: each statement carries claim_id, citation_verified from human review, and source_ref when verified.
- reviewed_fields, corrected_fields, required_facts, unsupported_facts; human_confirmed_blockers and reported_blockers.
- application_package: reviewed and required_rework booleans. Lack of an assessed package leaves the rework denominator undefined, not zero.
- confirmed_defects: defect_id, source_ref and summary with confirmed human attribution. A missed blocker must be listed as missed_blocker:BLOCKER_ID; opposite false GO/NO_GO as false_decision. Corrections require a recorded defect explanation.

Metrics are computed on human-reviewed observations only. No valid reviewer, missing attachment hash, no citations, undefined denominator, incomplete package review, duplicate run or evidence mismatch cannot yield ACCEPTED. Every confirmed error is emitted in the report for conversion to permanent regression tests. The acceptance scorer never places bids, signs or charges money.

    python -m src.modules.commercial_acceptance.acceptance score --manifest /external/apr06/frozen.json --thresholds docs/acceptance/apr06_thresholds_proposed.json --observations /external/apr06/operator-reviewed --output /external/apr06/reports/apr06-v1.json

Possible outcomes: INSUFFICIENT_REVIEW_EVIDENCE, PENDING_OWNER_THRESHOLD_APPROVAL, FAILED_ACCEPTANCE, ACCEPTED. Proposed thresholds always block ACCEPTED. Full human approval must be separately attributable and independently reviewed.
