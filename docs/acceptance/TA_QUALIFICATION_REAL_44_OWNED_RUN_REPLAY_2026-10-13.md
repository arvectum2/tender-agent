## Как воспроизвести

Утилита `scripts/acceptance/replay_original_44_owned_run.py` не имеет сетевых вызовов. Сначала сверяет исходные ZIP/PDF по сохранённым SHA-256. Затем во временный каталог копирует эти байты и создаёт **только временные метаданные прогона** из уже подтверждённой квитанции. Через временную подмену функций чтения метаданных вызывает **настоящую** `assess_owned_run_qualification` (не копию парсера). После положительного расчёта изменяет один байт **только во временной копии PDF** и требует, чтобы сервис отверг файл как `ORIGINAL_SOURCE_UNAVAILABLE_OR_UNSUPPORTED`.

```bash
cd /Volumes/ArvectumSSD/Arvectum/runtime/ta-qualification-real-run-replay-20261013
PDF=$(find /Volumes/ArvectumSSD/Arvectum/runtime/ta-scoring-alt-44-eok-20261013/0173300009226000009/evaluation -maxdepth 1 -type f -iname '*.pdf' | head -1)
/Users/master/arvectum-runtime/tender-agent/.venv/bin/python \
  -m scripts.acceptance.replay_original_44_owned_run \
  --soap-archive /Volumes/ArvectumSSD/Arvectum/runtime/ta-scoring-alt-44-eok-20261013/0173300009226000009/documentation-archive.zip \
  --scoring-pdf "$PDF" \
  --receipt docs/acceptance/alternate_44_1c_scoring_original_receipt_2026-10-13.json \
  --as-of 2026-10-13
```

**Проверенный реальный результат:** исходное `NOT_ASSESSED` с весами `60/40/5/95`, затем после изменения временной копии `ORIGINAL_SOURCE_UNAVAILABLE_OR_UNSUPPORTED` с `NOT_ASSESSED`. В отчёте указывается `tenant_database_accessed=false`, `production_saas_login_tested=false`, `original_documents_modified=false`.

## Что этот тест не утверждает

Это **не** реальное прохождение браузерной авторизации SaaS и **не** импорт в рабочий tenant ООО «Арвектум». Временные run metadata были собраны из ранее подтверждённой receipt и исходников **внутри теста**; таким образом доказана правильная работа маршрутизации на настоящих байтах, но **не** вся транспортная цепочка SaaS от сетевого получения документа до сохранения в production-БД. Тест не измеряет latency/SLO и не утверждает человеческую gold-оценку.

Для других закупок новая схема не используется без собственного подтверждённого оригинального документа и чёткой структуры критериев. Ноль выполненных контрактов не равен нулю баллов по специалистам и не является автоматическим квалификационным `NO_GO`. Срок и редакция относятся к полученным исходникам, а не к гарантированному текущему состоянию закупки.

Тестовый набор на изолированном checkout: **58 pytest PASS**, Ruff PASS, реальный ZIP/PDF integration replay PASS и `git diff --check` PASS на head `cecf94c`. Положительные и отрицательные unit-тесты утилиты используют только **синтетический документ**; подлинные ZIP/PDF остаются частными файлами Mac mini и не включены в GitHub.

Следующий безопасный этап — оценка пригодности ещё нескольких разных исходных документов и проверка ролевого SaaS-отчёта в отдельной тестовой БД; APR-06 независимый human-gold и пороги владельца, APR-07 production SLO сохраняются открытыми. Никаких изменений production, платежей, заявок или подписей при этой работе не производилось.
