# ChatGPT в чате через RDC — воспроизводимый source-audit Gemma

**Дата:** 12.10.2026. **Исполнитель:** Gemma4 12B локально на Mac mini. **Эксперт:** ChatGPT в текущем чате, читает документы через RDC; API OpenAI не используется.

## Реально проведённая проверка

Новая локальная утилита `scripts/acceptance/build_rdc_expert_packet.py` получила только уже существующие на Mac mini материалы:

- оригинальный протокол десяти запусков локальной Gemma `gemma_contract_second_opinion_private.json` (26 утверждений);
- независимый локальный SHA256-манифест `case-review-packets-private.json`;
- нормализованные файлы оригинальных архивов `tender_operator_demo/<run_id>/normalized/<source>.txt`.

Утилита повторно сверила цитаты с **полным сохранённым нормализованным текстом**, а не только с короткими фрагментами, которые ранее давались Gemma. Итог **22 точных цитаты, 3 форматных варианта, 1 отсутствующая цитата**. Полный пакет для проверки создан **только локально** по пути `evidence/tdp-r5/ai-expert-20261012/rdc-expert-packet-20261012.json`.

Несовпадение из-за форматирования не переводится автоматически в `LITERAL_MATCH`. Оба измерения корректны для своих баз сравнения, их нельзя смешивать.

## Как воспроизвести на Mac mini

```bash
python scripts/acceptance/build_rdc_expert_packet.py \
  --transcript /Volumes/ArvectumSSD/Arvectum/evidence/tdp-r5/ai-expert-20261012/gemma_contract_second_opinion_private.json \
  --manifest /Volumes/ArvectumSSD/Arvectum/evidence/tdp-r5/ai-expert-20261012/case-review-packets-private.json \
  --runs-root /Volumes/ArvectumSSD/Arvectum/evidence/tdp-r5/ai-expert-20261012/tender_operator_demo \
  --output /Volumes/ArvectumSSD/Arvectum/evidence/tdp-r5/ai-expert-20261012/rdc-expert-packet-20261012.json
```

Выводится ограниченный source-context и SHA нормализованного оригинала, без отправки исходников в другие сервисы. Утилита отвергает символические ссылки, обход каталогов, подменённые хэши, слишком большие документы и ложные/повторные цитаты. Она **не выполняет смысловую экспертизу** и всегда оставляет юридический статус `UNKNOWN`, коммерческий GO — `false`.

Экспертные смысловые выводы и исправления находятся в `docs/acceptance/TDP_CHATGPT_RDC_SEMANTIC_REVIEW_2026-10-12.md`; вопрос/ответ заказчика по исключительным правам и альтернативу антидемпинговому обеспечению нужно читать целиком, а не оценивать по отдельному короткому словосочетанию.
