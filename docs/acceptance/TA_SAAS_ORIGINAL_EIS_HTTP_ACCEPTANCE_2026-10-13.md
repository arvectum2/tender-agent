# APR-05/06 — HTTP-проверка SaaS на оригиналах ЕИС 44-ФЗ (изолированный тест)

**Дата:** 13 октября 2026 года. **Статус:** инженерная проверка API, не бизнес- или production-приёмка.

## Что было проверено

Вместо прямого вызова внутренней функции `assess_owned_run_qualification` тест проходит **обычные FastAPI-маршруты**:

- `GET /api/saas/runs/{run_id}/qualification` — отчёт о квалификации, только у owner/admin/analyst своей организации.
- `GET /api/saas/runs/{run_id}/report` — общий отчёт с квалификацией и отдельным ограниченным представлением для `viewer`.

С помощью обычного тестового `client` создаются **две разные тестовые организации**, изолированные токены Bearer, один тестовый run, отдельный приглашённый viewer. Юридическое согласие принимается **только внутри тестовых организаций**, а не от лица настоящего ООО «Арвектум».

После создания тестового run его локальные source metadata временно привязываются к **сохранённому официальному ZIP `getDocsIP` и PDF оценки**, скачанным ранее по закупке 44-ФЗ № **0173300009226000009**. Подтверждённые исходники перед запуском сверяются по SHA-256 с опубликованной мета-квитанцией; оригинальные файлы Mac mini остаются read-only и не копируются в Git.

| Проверка | Фактический результат |
|---|---|
| Нет Bearer-токена | **401** на квалификационном маршруте |
| Другая организация | **404** на обоих маршрутах, доступ к чужому run закрыт |
| Свой owner после законного согласия в тесте | **200**, источник подтверждён по оригинальному XML/UID/size/SHA |
| Исходный PDF оценки | 60% цена, 40% квалификация; внутри неё **5% подтверждённые договоры / 95% специалисты** |
| Коммерческий вывод по этому оригиналу | **`NOT_ASSESSED`**: референс-лист сам по себе не покрывает оценку специалистов |
| Владелец: общий отчёт | **200**, внутри квалификация с подтверждёнными критериями; `human_control_required=true`, `external_action_allowed=false` |
| Viewer: отдельный endpoint квалификации | **403** |
| Viewer: общий отчёт | **200**, только `REFERENCE_ACCESS_RESTRICTED`, без `criterion_source` и `qualifying_contracts` |
| Изменён один байт во временной копии PDF | `ORIGINAL_SOURCE_UNAVAILABLE_OR_UNSUPPORTED`, `NOT_ASSESSED`, критерии не раскрываются как проверенные |
| Настоящие исходные ZIP/PDF на Mac mini | **Не изменялись** |

## Как запускалось

Новый сценарий добавлен в `tests/test_apr05_saas_foundation.py`:

`test_http_source_bound_1c_qualification_through_tenant_roles[False/True]`

Первая параметризация использует маленький **синтетический оригинал** с той же структурой и позволяет выполнять проверку в GitHub CI без доступа к частным документам. Вторая считывает реальные байты при **явно установленной тестовой переменной**, например:

```bash
TA_TEST_ORIGINAL_EIS_44_CASE_DIR=/Volumes/ArvectumSSD/Arvectum/runtime/ta-scoring-alt-44-eok-20261013/0173300009226000009 \
  python -m pytest -q tests/test_apr05_saas_foundation.py
```

Если частный каталог не передан, вторая параметризация **SKIP**, а не симулирует наличие оригинала. В CI не отправляются закрытые документы, пользовательские Bearer-токены или исходные персональные данные.

**Локальный Mac mini на коде `9f488a4`:** 67 pytest PASS, Ruff PASS и `git diff --check` PASS при запуске с **реальным официальным** ZIP/PDF. Обычные предупреждения Starlette/httpx и SQLAlchemy про цикл таблиц не повлияли на результаты.

## Что остаётся открытым

Это полноценный **HTTP+auth тест в изолированной тестовой БД**, но не реальная сессия владельца в браузере и не проверка производственной системы. Исходные run metadata подготовлены в тесте на базе настоящих source receipts, а не получены от боевого ingestion. Подпись ЕИС не проверялась криптографически. Нет проверки полной пригодности ООО «Арвектум» к конкурсу, специалистов, условий трудовых договоров или юридического допуска.

Отдельные gates: APR-03B owner browser acceptance, APR-04 business accuracy компании, APR-05 юридическое/тарифное и staging approval, APR-06 минимум 20–30 независимых original-source решений и human-gold, APR-07 production SLO. `PR #416` останется DRAFT до штатной проверки и отдельного решения о слиянии. SaaS не включён, платежей, подписаний, заявок на ЭТП и развёртывания не было.
