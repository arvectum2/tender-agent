## Почему первый заход не сработал

Прямой `urllib.request.urlopen` вернул `URLError` по всем 20, что было честно отражено в отдельном приватном протоколе `official-live-20-receipt.json`. Затем проверен доступ через штатный системный `curl` с TLS, без отключения сертификатов, с запретом HTTP в перенаправлениях и с ограничениями. Пробник с неверным типовым путём `ea20` для Музея хлеба вернул 404; правильный `zk20` (исходный XML `epNotificationEZK2020`) вернул 200. На этом защищённом канале подтверждены все 20 карточек.
