## Отдельные обязательные quality gates

- Исполнитель Gemma обязан проверяться по **строгим** четырём XML полям, с блокировкой случая неправильного procurement ID; 67/68 недостаточно для автоматической привязки сделки.
- Параметры из сохранённого отчёта запрещено считать текущими, если источник старее последнего официального архива; новый архив также не равнозначен live edition.
- Допустить `VERIFIED` только при оригинальном точном source locator/quote с совпадением SHA и контекстной проверкой; без этого юридический/коммерческий тезис = `UNKNOWN`.
- Не отправлять заявки/письма, не подписывать GO, не обходить HTTP409; не изменять production.
- Следующий шаг автоматизации: сформировать на каждый кейс evidence-grounded legal-risk / contract-terms workbook с цитатами из всех доступных оригиналов, а ChatGPT вторым проходом проверяет цитату, смысл и применимость. Подлинно не полученные no_data и отсутствие цены/срока остаются UNKNOWN.
