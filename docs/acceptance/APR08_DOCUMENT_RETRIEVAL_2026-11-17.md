# APR08: поиск доказательств в документах выбранного запуска

Второй ограниченный вертикальный срез после PR610. POST `/api/demo/tender-agent/workspace/runs/{run_id}/evidence-search` использует существующую приватную операторскую авторизацию и проверяет защиту конкретного URL. Запрос до 240 символов, до 16 значимых точных слов. Только сохранённые обычные файлы текущего run с DP provenance и индексом чанков; до 24 записей, до 1 MiB нормализованного текста на файл, не более двух кандидатов для действующего `verify_operator_run_quote`. Вложенные paths не поддержаны текущим проверяющим модулем и не расходуют бюджет. Лексический поиск по локальному тексту — лишь выбор кандидатов, не доказательство. Перед выдачей проверяются оригинальные байты, URI SHA256, совпадение ID и хеша DP chunk и буквальной цитаты существующим проверяющим модулем. Ответ содержит только подтверждённый excerpt и координаты в извлечённом DP chunk, не страницы/ячейки, никакого ответа о юридическом или коммерческом смысле. При отсутствии подтверждения UNKNOWN, `scope_complete=false` всегда; отсутствие фрагмента не доказывает отсутствие требования. Данные не сохраняются, исходники не переписываются. В UI той же страницы добавлена отдельная форма, сброс результатов при смене запуска/запроса, вывод безопасным textContent.

Проверки: 105 целевых pytest PASS, Ruff, diff, JS syntax, Node DOM simulation PASS. Положительный end-to-end путь поиска через настоящий код существующего verifier и детерминированный DP adapter; изменённые оригинал/нормализованный текст/хеш, symlink, duplicate, неизвестный run, вложенный path и отсутствие совпадений отклоняются. HTTP 401/422/503 и разрешённый запрос проверены. Реальный архив 0372200172326000015: 6 нормализованных документов до последующего исключения вложенных XML, 2 кандидата, 0 подтверждённых цитат; повторная локальная диагностика обнаружила DataPlatformAuthenticationError на 127.0.0.1:8094 и вложенный XML. Все файлы сохранённого запуска побайтово неизменны. Авторизацию сервиса не меняли, credentials не извлекали; положительный replay реальных документов через живой DP пока не принят. Новый браузерный E2E и полное семантическое Q&A не подтверждены. Не объявлять модуль завершённым до полного DoD.
